# Entraday Full Website Package

Static multi-page website template for Entraday.

## Included pages
- index.html
- it-solutions.html
- products.html
- managed-services.html
- about.html
- contact.html

## Files
- styles.css
- script.js
- assets/logo.png (copied from the image you provided)
- README.md

## Deploy
1. Unzip `entraday_full_website.zip`.
2. Upload files/folders to your hosting document root (public_html/www/htdocs).
3. Ensure index.html is the default document.

## Customize
- Replace `assets/logo.png` with your finalized logo.
- Update page content as needed.
- For contact forms, integrate with a backend or a form service like Formspree or Netlify Forms.
